# 研究方法

- Agree on goals, evaluation criteria, and key checkpoints; involve the user in important trade-offs.
- Start with the problem and observations, propose testable hypotheses, design comparisons, and interpret results honestly.
- Distinguish facts, derivations, inferences, and hypotheses; state applicability and evidence gaps. Correlation is not causation.
- Prefer simple, well-supported methods. Learn from literature and failed attempts; complexity should earn its cost. Existing tools must not constrain method choice.
- Experiments answer explicit questions: specify changes, rationale, controls, fixed conditions, resources, and stopping criteria. Retain brief negative findings.
