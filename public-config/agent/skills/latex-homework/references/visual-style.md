# 作业视觉样式与验收

## 参照与取舍

用户认可的英文作业样式：TeX Gyre Termes 系列正文、NewTX 数学字体，深蓝大题与小问标题，黑色正文，细线结果框、三线表、简洁页眉和居中页码。重在字体协调、层次和疏密，不是增加装饰。模板是可编辑的近似实现，不声称逐像素复刻参考 PDF。

- A4，默认 22 mm 页边距、11 pt 正文；正文不缩小来塞页。
- 标题色默认 `#274D65`，正文黑色。不添加彩色底板、阴影、装饰图标或粗重边框。
- 大题使用“Problem 1 | Rates and inflation”层级，小问采用“(a) APR and effective annual rate”这样的说明性标题。数学变量保留正常数学字体。
- 页眉左侧课程、右侧作业名，细横线；底部页码。身份与日期按要求填写，默认无封面与整页大标题。
- 正文短段落，推导用 align 等环境在等号处对齐。框选最终答案，不框中间每一行。统一百分数、有效数字和单位。
- 表格用 booktabs，无竖线；图表主线用标题蓝色，辅助线用灰色，标注字号要可读。不因配色改变数据含义。
- 可按大题分页，但以最终页面为准：参考稿每题一页不是强制规则。不要强塞内容造成页脚拥挤，也不要用垂直拉伸制造大块空隙。
- 中文默认采用 ctex 与 Fandol 楷体：正文为常规楷体，标题和重点句用加粗楷体；Fandol 楷体无独立粗体字重，使用 `AutoFakeBold=2` 模拟加粗。保留既有色彩、布局及西文和数学字体；英文衬线字体不负责中文显示。

## 字体可用性

英文模板使用 `fontspec` 加载 TeX Gyre Termes，数学使用 `newtxmath`。先检查本机字体与宏包是否存在；例如有 TeX 工具时用 `kpsewhich newtxmath.sty`。若缺少依赖，不自动安装，也不静默替换后声称复现原效果。可以提出使用已有字体的降级方案，并说明视觉差异。

模板示例只是排版样本，替换为当前题目与答案后才能交付；不得把示例视作当前作业已核对的内容。

## 最小视觉验收

1. 实际编译 PDF，检查缺字、字体替代、越界警告；缺少编译器时明确未编译。
2. 用 `pdffonts` 核实实际嵌入字体，而不是仅检查源文件的字体声明。
3. 用 `pdftoppm` 等工具渲染并通过图像读取工具实际查看全部页面；仅提取文本不算视觉验收。
4. 检查长公式、表格边界、小问间距、标题与正文是否分离、最后一段与页码的距离。第 2、3、5 类密集页面尤其注意底部拥挤。
5. 修改字号、页边距、字体或全局间距后重查全部页面；局部改动至少重查受影响页面及分页相邻页面。
6. 交付说明区分源文件检查、编译通过、实际逐页查看。没有做到的步骤不写成已完成。
