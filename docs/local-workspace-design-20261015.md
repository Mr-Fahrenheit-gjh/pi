# 克制的工作区界面

## 目标与参考

让 Pi Web 从“功能同时铺开”转向“内容优先、操作按需展开”。保留已有主题、正文字体字号、Pi 标志大小与完整功能，不删除 API，不引入依赖。

参考：

- [Claude Design System](https://github.com/5j54d93/Claude-Design-System)：社区逆向整理，非官方设计规范。借鉴其语义色、细分隔、组件层级和克制的交互，不复制品牌素材或受限字体。
- [Claude Artifacts](https://claude.com/features/artifacts)：对话与工作内容分区，结果作为可持续查看的对象，而非全部塞进聊天正文。
- [Claude Code 网页端](https://code.claude.com/docs/en/claude-code-on-the-web)：任务、会话与工作环境的组织方式。不是把它的云端仓库工作流照搬到本地 Pi。

未核实到官方完整的 Figma 开源稿，不把社区复刻、Figma 插件或第三方尺寸推断称为官方设计。

## 界面约定

| 区域 | 默认显示 | 按需展开 |
| --- | --- | --- |
| 桌面顶部 | 标题下拉、代理图标、分支、文件入口 | 完整历史、自动命名、会话信息、系统提示词、工具定义 |
| 侧栏底部 | 设置 | 模型、技能等继续通过设置导航访问 |
| 文件区 | 终端、改动、更多、搜索 | 原文件夹、上传、刷新、忽略文件视图 |
| 输入区 | 中性输入卡片、附件、模型、上下文圆环、图标发送/停止、选项入口 | 推理级别、工具预设、压缩、声音；运行中发送方式在常规设置调整 |
| 回答 | 正文、厂商/模型标识、复制、时间 | 逐条消息的 token 统计；界面不展示计费 |
| 文件预览 | Source/Preview/Diff、引用、Finder、下载 | 窄面板的类型/行数/体积通过路径提示查看 |

停止运行、停止压缩、权限确认、限制模式提示及需要处理的错误不能随设置一起隐藏。思考与工具的原默认折叠、真实父子代理和工作区状态恢复保持不变。

参考用户补充的 Claude 顶栏截图：标题自身是下拉入口，不另放省略号；顶栏与正文同底色，不铺一排按钮，也不复制套餐、升级或无实际能力的分享入口。代理入口保留图标与必要的子代理数量。聊天和文件工作区顶栏对齐，文件标签采用轻量选中态。

桌面菜单复用 `SidebarMenu` 的定位、键盘与焦点归还，不增加另一套菜单基础设施；独立视图开关使用 checkbox 语义。系统/会话信息面板可用 Esc 或外部点击收起，不覆盖在聊天上常驻。输入区沿用现有选择器，外层增加按需展开入口；Esc 优先收起内部选择器，再收起整个选项组。

运行中只有一个图标发送入口，默认引导当前任务。常规设置可切换为当前任务结束后发送（仅浏览器偏好，不改模型或全局配置）；原 Alt+Enter 队列快捷键保留。停止运行和停止压缩仍直接可达，只展示图标和悬停/无障碍名称。输入框在运行中不改变边框颜色。

上下文在输入区底部显示中性圆环，悬停显示比例和 token 数，点击打开原会话信息面板；费用不出现在顶栏、会话信息或逐条消息用量中，底层统计/API 不删除。

`app/workspace.css` 是基于现有主题变量的界面层，不是新增主题。内容字号、字体、主题默认值和 Pi logo 不在此覆盖。支持系统的减少动效偏好。桌面文件操作区从七个按钮收为四个，保持终端与改动的状态可见。

## Finder 定位合同

沿用 `/api/open-in-explorer`，只新增可选布尔字段 `reveal`：

```json
{ "cwd": "/absolute/path/to/file.md", "reveal": true }
```

- 缺省仍是原有的打开目录行为；`reveal: true` 必须指向普通文件。
- macOS 使用 `open -R <file>`，定位并选中原文件，不是打开下载副本；Windows 使用 Explorer 选择文件；Linux 打开父目录。
- 保留本机请求限制、允许根目录、真实路径/软链接检查；不启用 shell。
- 浏览器确认可用后才展示原生操作；失败有简短提示且可重试。已删除文件不展示定位或下载。

## 验证与维护

相关单测覆盖菜单收纳、两种侧栏布局、输入/停止操作、消息用量折叠、文件预览、路径授权与软链接逃逸。API 测试在导入前替换原生 spawn，并同步 Node ESM 内置导出，不能用单测打开真实桌面窗口。

`e2e/workspace-design.mjs` 提供隔离夹具和可序列化的浏览器检查函数，经现有 headless playwright-mcp 执行，不启动另一个浏览器、不调用模型、不写入用户会话。覆盖新会话、长对话、标题菜单、圆环与无计费界面、图标发送和默认引导/可选队列模式（拦截两次测试提交，不调用模型）、文件 Source/Preview、Finder 请求/失败重试、窄分栏、直接停止及权限确认、设置与主题切换。

实际候选、BUILD_ID、验证结果、运行进程与未上线状态只维护在工作区 `工具/pi-web维护/整体界面-20261015/README.md`。新行为已加入 `local-customizations.json` 的迁移保留合同。
