# 侧栏分支会话树

分支会话显示在来源会话下方，默认展开。每级缩进 16px，并保留连接线和独立展开按钮。八级之后不再增加视觉缩进，避免挤掉标题；数据层级不截断。

## 展示与会话身份分开

`lib/session-tree.ts` 在置顶区、每个项目组和归档项目组内建立分支森林，再输出供虚拟列表使用的行。父行先于后代；兄弟保留原排序，整棵树按其中最高优先级的成员排序。主列表是最新活动，置顶区是置顶时间，归档区是归档时间。

每个 fork 仍是独立 `SessionFamily`。置顶、归档、删除和运行状态判断只使用原 family，不把分支后代并入它。折叠行的 `branchStatus` 仅用于提示隐藏后代的运行或未读活动。

只有同一展示区域中的来源才能形成父行。来源缺失、跨项目、位于另一置顶或归档区域时，分支作为当前区域的根显示。来源为 subagent 时挂在其可见的所属 family 下。自环或环链切断一条边，保证每个会话只显示一次；展开采用迭代遍历。

分页按树根计数：项目组初始六棵树、置顶区八棵树，每次增加二十棵。展开后代跟随其根，不计入“显示更多”的隐藏数。选中、运行或未读的后代能使整棵树进入可见范围。

## 展开状态

`SessionSidebar` 保存页面内展开选择，不写会话文件。选中路径变化或来源信息首次补全时打开祖先；目录轮询不覆盖手动折叠。`SessionTree` 的展开按钮独立于主链接，点击不选择会话，支持键盘和 `aria-expanded`。

## 验证入口

- `lib/session-tree.test.mjs`：层级、独立 family、缺失来源、跨区域、循环、分页、归档和折叠状态。
- `components/SessionTree.test.mjs`：按钮语义、缩进、隐藏活动提示、原链接及操作。
- `e2e/sidebar-forks.mjs`：隔离候选夹具和浏览器检查，覆盖三层缩进、折叠不选中、导航、轮询保留折叠、深链接、独立置顶、桌面与紧凑布局。夹具仅写 `/tmp`；代理命令被拦截，不发模型请求。

按 pstack 的 Model the Domain 原则，在行模型建立森林，而不是用 CSS 猜来源；按 Prove It Works 原则，同时检查行模型和实际构建的浏览器行为。保留原 `session-family` 是为了不把显示层级变成级联删除关系。
