# 本地内核 1.3.0 与上游非冲突优化

## 范围与保留合同

用户批准把 Web 内嵌内核从 1.2.0 升至 1.3.0，并吸收不会干扰现有定制的上游优化；冲突以本地标准为主。Web 包版本保持 0.12.1，不宣称整包已升级为 0.12.2。

七个 `@earendil-works/pi-*` 包统一精确固定到 1.3.0。没有升级其他依赖，不修改模型、授权、MCP、凭据或会话设置。恢复适配器仍同时校验普通与 bundled AgentSession；外置子代理 runner 仅对经核实的稳定 1.2.0/1.3.0 允许无 chord，未知版本、预发布和声明 chord 的宿主保留严格检查。

保留暖白主题、字体字号、粗体、Pi logo、无框回答、实色悬浮侧栏、Ghostty、无终端工具栏、右侧待办/只读子代理、隐藏费用、默认引导、过程折叠及新对话底部无目录入口。

| 上游提交 | 吸收理由 |

## 本轮不吸收

- 新主题和色板、暗色文字/边缘视觉、终端主题切换：避免覆盖当前视觉与 Ghostty 合同。
- 费用/缓存提示、代理切换器 token/费用统计、每轮耗时常驻：不恢复已删除的冗余信息。
- 上游代理侧栏布局与归档批量操作：不替换本地右侧待办/只读代理设计。
- 内置子代理 worktree/输入预算改动：当前使用外置 pi-subagents，不能把上游内置实现测试当成外置插件验收。
- 其他文件面板、上传、Markdown 链接新功能：与当前附件/访问策略有交叉，非此次稳定性优化必需。
