# Pi 输入建议维护约定

- 保留固定上游来源、MIT 许可与可重放补丁，TUI 和 Web 共用一份生成逻辑。
- 只注册本地适配包，不同时启用原 npm 扩展。使用当前宿主 registry API，不复制 SDK 内部实现。
- `enabled`、`tuiEnabled`、`webEnabled`、`acceptTab` 默认开启。建议只填入草稿，不自动发送或视作用户授权。
- Web 通过现有 `setWidget` 协议适配，不给 `ctx.ui` 添加私有字段。改载荷时同步两端与会话隔离测试。
- 合成供应商浏览器测试不调用真实模型，不能替代真实历史或正式发布验收。最终候选和临时服务遵守 Pi Web 维护流程。
